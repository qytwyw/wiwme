# Wiwme — 轻量级本地 Markdown 编辑器

一款专注于本地文件编辑、界面精致、开箱即用的 Markdown 编辑器。无需注册、无需建库、绿色便携，只为专注写作而生。

## 🎨 界面与外观

### 多主题系统
- 内置亮色 / 暗色两套默认主题，一键切换
- 支持加载第三方主题包，轻松定制整体视觉风格
- 目录支持两种模式，都可通过主题 CSS 文件深度自定义

### 笔记本风格背景
编辑器提供多种书写背景可选，还原真实纸笔体验：
- 网格背景
- 横线背景
- 点阵背景


### 可视化设置面板
绝大多数功能与外观偏好均可在设置界面直观调整，无需修改配置文件，包括字体、间距、背景、快捷键行为等。

### 标签页状态标识
不同状态的文件在标签页上以醒目颜色区分，一目了然：
- 已保存文件
- 已修改未保存
- 新建空白文件
- 新建且已修改

## ✍️ 编辑能力

### 所见即所得
基于 Tiptap 内核的实时渲染编辑模式，边写边看最终效果，无需频繁切换预览。搭配精美工具条与右键操作菜单，常用格式一键触达。

### 双面板编辑
- 支持左右 / 上下双面板布局，自由切换方向
- 标签页可在面板间拖拽移动，方便多文件对照编辑

### 自动缓存保护
编辑器会按固定频率自动缓存正在编辑的内容，异常退出或关闭后再次打开可自动恢复，避免内容丢失。

### 双模式目录栏
目录栏提供两种视图，按需切换：
1. **传统标题目录**：完整展示各级标题与内容层级
2. **精简大纲**：仅显示标题结构，专注文章骨架梳理

## ⚡ 效率工具

### 侧边栏速查
侧边栏集成两大参考面板，编辑时随时对照：
- **快捷键速查**：全量快捷键清单，提升操作效率
- **Markdown 语法手册**：常用语法示例与说明，边写边查

### 文件收藏夹
将频繁访问的文件加入收藏，在侧边栏收藏夹中一键打开，无需层层查找目录。

### 多格式导出
支持将 Markdown 文档导出为多种格式：
- HTML 网页
- JSON 结构化数据
- 纯文本

> 后续规划支持 PDF、Word 等更多格式导出。

## 🚀 快速开始

1. 下载最新版本压缩包
2. 解压至任意目录
3. 双击运行主程序即可开始使用
4. 通过菜单「打开文件」选择本地 Markdown 文件，或直接新建开始写作

---

## 🎨 自定义主题

1. 以程序目录的 `themes` 文件夹中附带的主题为模板，按需修改 css，自用或感觉不错的话提交到仓库分享给大家，记得在说明文件里留下您的作者名。
2. 按照主题规范编写样式，可自定义配色，后续甚至可以直接修改 UI。
3. 在设置 → 外观中选择新加载的主题即可生效
